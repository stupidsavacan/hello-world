# mahjong/_junkyard

This directory is intentionally inert.

It is a museum, landfill, and witness-protection program for files that have been deleted, resurrected, renamed, body-swapped, or otherwise denied a dignified lifecycle.

Nothing here is part of the active isolated mahjong runtime. Do not import it. Do not depend on it. Do not mistake filename continuity for identity continuity.

Current exhibit theme: **the resurrection succeeded, the identities did not.**
